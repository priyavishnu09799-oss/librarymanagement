Library Management System

A C-based Library Management System designed to manage books efficiently using file handling. The system allows users to add, update, remove, search, view, issue, and return books. Book details such as Book ID, title, author, and quantity are stored in a file for persistent data management.

Technologies Used: C Programming, File Handling, Structures

Key Features:

Add new books
Update book details
Remove books
Search books by Book ID
View all books
Issue and return books
List issued books
Store book records using file handling
